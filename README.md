# 📝 TaskFlow - Minimalist To-Do Application

TaskFlow is a sleek, responsive, and high-performance To-Do application built with pure Vanilla JavaScript. It allows users to manage daily tasks efficiently with persistent data storage using the browser's LocalStorage.

#  📝 Modern To-Do List Application
A sleek, responsive, and user-friendly To-Do List application designed to help users manage their tasks effectively. This web app allows you to track project milestones, set due dates, and monitor your overall productivity through a dynamic progress dashboard.

# 🚀 Features
Task Management: Add new tasks with specific descriptions and track their status.

Due Date Integration: Assign deadlines to each task to ensure timely completion.

Dynamic Dashboard: View real-time statistics including:

Total Tasks: Total count of entries.

Completed: Number of tasks marked as done.

Pending: Number of tasks still awaiting action.

Progress Percentage: A visual calculation of your productivity (e.g., 50%).

Interactive UI: Use the 'Actions' panel to toggle task completion (check) or remove tasks (delete).

Visual Status Indicators: Tasks are clearly labeled with green "Done" icons or hourglass "Pending" icons.

## 🚀 Key Features

-   **Persistent Storage**: Tasks remain saved even after refreshing the page or closing the browser.
-   **Inline Editing**: Update task descriptions on the fly without complex menus.
-   **Dynamic Date Header**: Automatically displays the current date for better daily planning.
-   **Task Management**: Add, delete, and toggle completion status with intuitive UI feedback.
-   **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.
-   **Animations**: Smooth entry/exit animations for a premium user experience.

---

## 🛠️ Tech Stack

-   **HTML5**: Semantic structure for better accessibility (A11y).
-   **CSS3**: Custom properties (Variables), Flexbox, and Glassmorphism effects.
-   **JavaScript (ES6+)**: DOM Manipulation, Event Listeners, and LocalStorage API.
-   **Icons**: FontAwesome 6.0.
